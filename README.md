Проект автоматизации тестирования веб приложения Яндекс-самокат c помощью паттерна page object 
Проект содержит автотесты для проверки функциональности веб-приложения Яндекс-самокат.

Тесты написаны с использованием:
- Python
- Selenium WebDriver
- Pytest
Реализованные проверки
1. test_FAQ - Проверка раскрытия вопросов на главной странице и корректности текста ответов.

2. test_order - Проверка положительного сценария оформления заказа:
заполнение формы
выбор станции метро
выбор даты
выбор срока аренды
подтверждение заказа
Тесты параметризованы (разные наборы данных).

3. test_navigation - Навигация
Клик по логотипу «Самокат» → переход на главную страницу
Клик по логотипу Яндекса → открытие Дзена в новой вкладке
